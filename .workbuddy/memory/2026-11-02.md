## 全模板照片位（用户要求"必须全部都能支持放照片"）

- 之前：JS photoFrame 无照片返回 null + CSS `:has(img[hidden]){display:none}`，20 模板全部看不到照片位置；editorial 骨架完全没有照片
- 现在：5 骨架（head/split rail/banner band/editorial header）全部渲染照片框，空态为取景框样式（浅色渐变底+姓名首字+小字"照片"），深色侧栏/横幅自动用白色半透明变体
- 服务端与 JS 均带隐藏 img（保证打印规则匹配）；@media print 与导出预览页隐藏空照片位（PDF 不会出现虚线框）
