## 架构验收硬条件

1. `frontend/base.html` 不加载 `app.css`、`refresh.css`、`interface.css`、`workbench.css`、`overview.css` 或旧全局 `app.js` / `career.js` / `studio.js`。
2. 活跃 UI 统一位于 `app/templates/frontend/` 与 `app/static/{css,js}/frontend/`；复用稳定的安全简历文档宏，而非复用旧 UI。
3. 新组件使用统一 `cf-*` 命名、统一 Token，禁止各页再次建立覆盖栈。
4. 所有现有功能必须有明确入口与完成/失败路径，不能只做静态按钮或虚构后台进度。
5. 暂时保留的旧文件不参与页面渲染与资源加载；用户原有未提交代码不得被清理或带入本次提交。
