# 管理后台与服务接入阶段记录

本轮在现有 V1 上增加初始管理员引导、管理权限、独立管理导航、运营概览、用户只读列表、邮箱与模型配置版本、审计记录。界面沿用职序设计 Token，用户工作台仍以简历、岗位与报告为核心。

管理员配置的保存流程为草稿 → 校验 → 确认发布；回滚创建新的发布版本。模型配置切换影响新报价，已报价任务在确认时检查配置版本，已开始执行的任务沿用原版本。邮箱和模型密钥以本地独立加密密钥加密存储在 MySQL；响应、页面和审计不返回明文。原本的本地环境配置作为未发布管理员配置时的回退。

当前本地 `.env` 已安全存入用户提供的邮箱授权码与模型服务地址/密钥，并被 Git 忽略。因缺少发件邮箱地址、模型 ID 和费用上限，QQ 发信与真实模型调用均未启用或验证。服务密钥曾出现在聊天消息中，正式上线前宜在供应商控制台轮换。

初始管理员命令：`uv run flask --app wsgi bootstrap-admin <邮箱>`。命令仅在还没有管理员时创建账号，随机临时密码写入忽略提交的 `instance/admin-first-login.txt`，不输出密码到普通日志。待用户提供目标邮箱后执行；目前未创建真实管理员账户。首次登录后的密码更改/重置功能仍需实现，临时凭据文件应在交付后删除。

已验证：135 项后端测试通过，33 项 Chromium 浏览器测试通过；隔离 MySQL 测试库验证升降级、备份恢复和中文/emoji 数据，共 20 张表（含迁移表）。Ruff、格式检查、前端构建与 `git diff --check` 通过。Python 覆盖率为语句 98.30%、分支 93.43%；不能宣称所有源码分支覆盖。模型协议仍只用本地模拟服务验证，未产生真实模型费用。测试后 Web、worker、Mailpit 与项目 Redis 已停止。

尚未交付：提示词管理与按功能模型路由、会员/订单/模拟支付、管理员会话撤销、账户生命周期、完整 Agent、OCR 与其余 V1 管理模块。Agent 的建议方案见 `AGENT_DESIGN_PROPOSAL.md`，需先完成讨论再落地。
