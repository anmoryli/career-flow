# 默认决策与用户更新

- 2026-10-21：用户明确要求不使用 Docker。该要求覆盖初始提示词中容器相关交付项。采用已有 WSL Ubuntu 的原生 MySQL/Redis 与 Windows 原生开发进程；旧容器配置已移出活动工程，归档到忽略的 `output/legacy-container-config/`。
- 固定 V1，不创建 V2/V3，不替换 Flask、MySQL、HTMX/Alpine。
- 使用唯一 `DATABASE_URL` 解析连接；MYSQL_* 为初始化辅助变量，应用不再拼装第二套连接来源。
- 原生开发端口 3310/6390/1026/8026，避免重新连接先前的容器服务。旧配置单独保存在忽略的 `instance/config-backups/`。
- 时间统一使用 UTC；表中保存无时区 UTC datetime，页面日期明确标识 UTC。
- 邮箱统一小写；密码保留首尾空白并使用 Werkzeug scrypt。
- 会话是固定 30 天有效期，不是无限期登录。数据库只存随机会话 Token 的 SHA256 摘要。
- 用户明确确认的事实才进入上下文；模型未配置时仅保存个人记录，不返回模拟 AI 文本。
- 模型、PDF、OCR、Agent 框架等在对应阶段按需求引入，当前不安装尚未使用的大型依赖。
- 当前列表有数量上限，分页/自动摘要为后续工作；不把这一批实现当作完整 V1 验收。
