# 职序 CareerFlow V1 用户真实体验验收

> 用途：请测试者像第一次使用产品一样，从注册开始完成一轮真实求职准备，并记录实际感受。按顺序操作；每项勾选“通过 / 问题 / 未测”，遇到问题记录页面、操作步骤、预期结果、实际结果和截图。不要只凭页面看起来正常就判定通过。

> ⭕ 表示括号中的修改要求已完成或已有实现经核查；原有 √ 是测试者的记录。未圈项目仍需修改或实际体验复测。

## 测试前准备

- 在指定的 V1 验收环境操作，不在生产环境试验管理员配置、测试支付或注销。
- 准备一个可收信的邮箱、一个单独的测试账号，以及一份可用于测试的简历和目标岗位描述。可用合成资料；若用真实简历，请先确认测试环境和数据处理方式符合本人要求。
- AI 功能只有在验收环境已配置可用模型时才测试。模型请求可能产生供应商费用，也可能消耗账号权益；先由测试负责人确认模型配置和费用上限。不要为排障重复点击 AI 按钮。
- 会员购买目前没有真实支付渠道。只有验收负责人明确启用本地模拟支付时，才可在隔离环境验证开通流程；该流程不代表真实支付验收。
- 记录浏览器、操作系统、屏幕尺寸、账号套餐、开始时间和使用的资料类型（真实 / 合成）。建议桌面端完整走一遍，再用真实手机完成关键流程。

- [ ] 上传一张个人照片，调整布局后保存；刷新或重新打开简历，照片和设置是否仍在？

- [ ] 打开历史版本，查看旧内容，再复制为一份新简历并修改副本；基础简历是否保持原样？
