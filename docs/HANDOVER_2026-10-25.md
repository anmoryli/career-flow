## 六、环境与已知坑（重要）

1. **PowerShell 内联 `python -c` 多行/中文引号必炸** —— 写临时脚本文件到 `C:\Users\Administrator\AppData\Local\Temp\opencode\` 再 `uv run python xxx.py`
2. **控制台 GBK 显示中文乱码是假象** —— 文件本身是 UTF-8，验证内容用 `read` 工具或 Python 读取，不要因乱码改数据
3. **改 Jinja 模板后必须重启 Web 才生效**（Flask `--no-reload` + 模板缓存）：`Stop-Process -Id (Get-Content instance\native-web.pid) -Force` 再跑 start-native.ps1；仅改 CSS/JS 静态文件只需 `npm.cmd run build`
4. **`npx playwright` 要用 `npx.cmd`**（执行策略拦 `.ps1`）；Tesseract 要在 PATH（`C:\Program Files\Tesseract-OCR`），否则 OCR 用例跳过
5. **管道输出的 exit code 1 可能是 stderr 误报**（`git push`/`npm build` 成功也报 1）——用 `cmd /c "... > file 2>&1"; $LASTEXITCODE` 复核
6. **测试隔离**：集成测试必须用 `TEST_DATABASE_URL` 指向 `careerflow_test` 库（`scripts/test-integration.py` 自动处理）；顺序跑偶发状态残留，单独重跑可区分真假失败
7. **CSP 很严**（`script-src 'self'`，无 inline handler/eval）——前端交互一律 addEventListener + data 属性；用户浏览器扩展报的 CSP 错误与本项目无关
8. `.env` 有真实 QQ 授权码和 MiMo key（gitignore），**不得写入源码或测试**；上线前建议轮换（曾在聊天中出现）
