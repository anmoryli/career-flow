# V1 简历模板设计与 Skill 调研

本次重新设计现有 20 个行业模板，保留原模板 ID、用户数据、编辑与导出接口。模板仅决定排版，不添加经历、技能等级或业绩。

## 网上搜集的 Skill

以下资料作为设计研究阅读，没有安装或运行第三方脚本，没有引入其渲染引擎或复制模板源码。

| Skill / 资料 | 来源 | 本项目采用的原则 |
|---|---|---|
| Resume / CV Builder | https://github.com/dabydat/resume-builder-skill/blob/master/skill/SKILL.md | 根据目标岗位组织内容，技能用真实文字表示，强调可读性与日期对齐 |
| CV Builder | https://github.com/MusannaAmmar/cv-builder-skill/blob/main/SKILL.md | 模板应通过真实预览图片比较，姓名、正文与辅助信息有稳定字号层级 |
| TerminalSkills CV Builder | https://github.com/TerminalSkills/skills/blob/main/skills/cv-builder/SKILL.md | 用结构化数据切换模板，生成 PDF 后检查溢出和分页 |
| Harvard Bullet Point Resume Template | https://careerservices.fas.harvard.edu/resources/bullet-point-resume-template/ | 克制的单栏、清晰章节、经历条目和一致日期 |
| RenderCV | https://github.com/rendercv/rendercv | 对比不同字体、分隔线与版式节奏；最终交付检查实际渲染 |

外部 Skill 关于强制量化、最多两页、默认不放照片等建议不直接成为产品规则。经历只能来自用户真实内容，照片由用户选择，单页自适应遵循本项目已确认要求。

## 排版方向

统一使用 A4 纸张、系统中文字体、清楚的姓名区、11–12px 辅助文字和 13.5px 基准正文。姓名、目标职位、联系方式位于整页顶部；双栏将教育和技能放入辅栏，工作与项目保留在主栏。编辑式模板使用左侧章节标签、右侧正文，取消不完整的章节编号。章节按自然内容高度排列，取消将短简历的章节强行等距撑满整页的规则。单页缩放继续作用于超页内容。

| 模板 | 排版重点 |
|---|---|
| 技术项目 | 宽幅项目正文、右侧技术清单 |
| 后端服务 | 整页姓名区、等宽日期、经历主栏 |
| 算法 | 白底双栏、细线实验章节 |
| 简约现代 | 整页姓名区、教育技能辅栏、开放正文 |
| 产品经理 | 顶部细线、浅色章节条 |
| 设计师 | 暖白纸面、大字号姓名、左侧章节标签 |
| 市场运营 | 非对称姓名区、活动与项目正文 |
| 销售商务 | 窄侧栏、清楚的业务段落 |
| 通用商务 | 标准单栏、双线姓名区 |
| 金融财务 | 居中标题、衬线字形、精确日期 |
| 人力行政 | 暖灰侧栏、短线章节标记 |
| 教师教研 | 细虚线时间轴、课程与教研段落 |
| 应届校招 | 浅色姓名区、教育与实习内容 |
| 医疗健康 | 白底青灰栏、临床正文与资质清单 |
| 法律合规 | 墨色衬线、正式单栏 |
| 工程制造 | 灰蓝结构线、项目抬头与参数文字 |
| 公共事业 | 联系方式网格、浅灰章节条 |
| 高级管理 | 大姓名、双细线、开阔正文 |
| 双语材料 | 中英章节、简洁正文 |
| 职业转换 | 左侧姓名标记、能力与经历细线段落 |

## 验收方法

- 逐一生成 20 个模板的实际浏览器截图与 PDF，检查姓名、联系方式、经历、技能和日期。
- 在桌面和手机上检查目录及编辑预览，照片缺失时 PDF 不出现空占位框。
- 检查实际 PDF 页数和边界，保留超页内容的自动单页缩放。
- 检查保存、重新加载、隐藏章节与中英标题，确保 Jinja 和浏览器渲染保持一致。
- 不使用随机技能圆点、进度条或虚构百分比。
## 当前实现：恢复与排版修复

两轮试验版式均已撤回，恢复此前的 20 个行业模板及其单栏、分栏、时间轴、横幅、编辑式结构。保留用户已要求的超页自动单页缩放，以及技能仅展示真实文字的规则。

本轮修复：

- 编辑预览、导出预览和打印使用相同的文档字体、内边距、段落间距与栏宽。
- 适配屏幕尺寸使用显示变换，避免低比例 CSS zoom 改变技能标签的换行。
- 单页内容压缩与窗口显示缩放分别计算；整张 A4 的可视宽度保持完整。
- 恢复教育经历、照片与姓名在原模板中的位置。
- 修正经典模板重复嵌套的标题容器。
- 对齐浏览器与 Jinja 的经历段落结构，导出时保留项目链接。

## 验收方法

- 20 个模板逐一保存，分别检查桌面和手机上的编辑器、导出预览与实际 PDF。
- 按 A4 宽度归一化比较各章节的水平位置、垂直位置和宽度，而不是只检查 PDF 文件存在。
- 检查纸面预览完整落在屏幕内、PDF 为单页，以及保存、重载、隐藏章节与超长内容压缩。
- 实际图片保存在 `output/resume-design/desktop/` 与 `output/resume-design/mobile/`。
