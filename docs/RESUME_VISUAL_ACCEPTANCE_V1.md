# V1 简历模板视觉复核

本轮按真实截图完成 20 套模板的视觉复核，并根据发现的问题进行两轮修改。这里记录的是开发侧已经执行的美观检查与修正，功能测试另外记录，不用“PDF 能生成”代替视觉判断。

## 检查标准

1. **字体层级**：姓名、章节、经历标题、正文、日期和联系方式可区分；标准正文基准为 12px，紧凑与宽松选择仍然有效。超长简历遵循已确认的单页整体压缩规则。
2. **对齐与间距**：经历标题与日期对齐；职位、城市、角色和技术栈之间有间距；GitHub 等短标签不拆行；长链接允许在值区域换行。
3. **留白与完整性**：章节自然排列，侧栏背景延伸到纸张底部；不通过给章节塞入巨大空隙填满页面；正文与边界不相交。
4. **颜色与层级**：深色侧栏标题和辅助文字可辨认；医疗标题减轻色块重量；人力模板圆角保持克制；行业模板之间保留原有结构差异。
5. **内容真实性**：技能不显示虚构熟练度，不出现不完整的章节编号；模板说明与实际预览相符。
6. **一致性**：桌面、手机、编辑器、导出预览与 PDF 使用同一套文档尺寸规则。

## 已修正的问题

- 分栏底色在内容结束处突然中断：改为贯穿纸张，文字仍按自然间距排列。
- 标准正文及辅助信息过小：增加正文、经历标题、日期、侧栏和技能文字的基准字号。
- 职位与城市、角色与技术栈连在一起：增加分组间距并隐藏空字段。
- GitHub 标签被断成两行：固定标签不拆行，保留链接值的换行能力。
- 设计、市场模板出现孤立的章节编号：关闭不完整编号，并增大设计模板的章节标题。
- 医疗模板的标题色块过重：改为浅色底与深色标题。
- 人力模板的章节圆角过大：收敛为 2px；增加小标签字号。
- 目录说明与实际布局不符：逐一重写 20 套模板说明，使用实际存在的结构特征。
