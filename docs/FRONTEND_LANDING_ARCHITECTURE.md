# V1 Landing 主导的信息架构

本轮基线 f8f56f5。审计发现：固定五项登录后导航、独立总览、垂直管理/分析/编辑导航和封面卡片网格共同决定了控制台体验；单独改首页不能改变这一点。

## 入口与任务路径

- `/` 和 `/workspace?view=dashboard` 共用 `frontend/_landing.html`，前者介绍产品和任务，后者使用真实简历/运行中分析/已完成结果提供继续行动。不展示后台指标；登录跳转和既有路由保持兼容。
- 产品导航：写一份简历、准备一个岗位、我的内容。报告/记录/模板收进内容菜单，账号/会员/管理保留账号菜单入口。品牌始终返回产品首页。
- 创建/导入/模板 → 编辑与预览 → 段落 AI 对比与采用 → 岗位要求/证据 → 追问 → 审阅并另存岗位版本。每一步连接现有业务接口，没有静态替代结果。
- 简历库是重点最近文档和连续目录行；模板是连续版式章节。编辑器保留必要的内容/预览双区，垂直图标导航改为横向板块定位。
- 岗位库下置；诊断来源顶部展开；审阅为横向定位加原文/候选对照，不再三栏侧边控制台。报告/历史是内容目录，个人记录正文与确认事实依序阅读。
- 设置按章节组织，会员按准备方式组织；管理采用横向功能导航，统计改为真实业务摘要，列表与服务配置功能保留。

## 统一自定义下拉

`js/frontend/select.js` 将所有活动单选 select 增强为 combobox/listbox，包括动态生成字段。原字段仅作不可见表单来源，保留 id/name/value/required/disabled 和 FormData；不使用原生菜单作为正常交互。

支持指针、方向键、Home/End、Enter/空格确认、Escape 关闭、Tab 离开、首字输入、选中/禁用状态、动态选项及程序赋值同步。原有字段验证会聚焦自定义触发器，错误描述保持关联。弹层优先使用原生 Popover 顶层能力（列表视觉为自定义），放在所属 dialog 内以保持模态可用；不支持时用固定定位回退。脚本不可用时原字段仍可使用。

## 实施边界

活动模板/CSS/JS、必要测试与文档调整；没有新增框架/依赖、数据库变更或业务 API 变更。鉴权、CSRF、权限、会员、账本、幂等和简历不可变版本规则保留。AI 候选仍须核对后明确采用。

共享 `landing.css` 定义产品入口、导航、任务页首、管理横向导航；功能布局留在所属 feature 样式。浅/深/系统主题继续共享 Token；入场、状态与预览动效遵守 reduced-motion，文档 A4 字体不随界面重排。
