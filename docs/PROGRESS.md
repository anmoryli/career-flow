# V1 实施状态

## 已落地的首批功能

- 工程：Python 3.12、Flask、MySQL/Alembic、Redis/RQ、前端构建、CSRF、CSP、错误脱敏。
- 设计系统：Token、浅色/深色/系统、登录同步、响应式首页/认证/工作空间/对话。
- 认证：本地邮件验证码、密码登录、30 天可撤销会话、全设备退出、限流。
- 对话：按用户隔离的持久化记录、消息幂等、确认事实、上下文预算、删除级联。
- 2026-10-21 按用户要求切换至原生运行，全部后续验证使用原生服务。
