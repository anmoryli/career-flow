# 页面资源映射与上传控件

## 资源所有权

`app/web/frontend.py` 是页面→模板→资源与共享外壳信息的唯一注册表：

- `WORKSPACE_PAGE_SPECS` 定义各工作空间页面的模板、功能CSS/JS、当前视图、访客可访问标记、编辑器与流程导航标记。路由使用同一对象取模板并沿用原先四个访客入口；未知视图仍回落到dashboard。
- `WORKSPACE_PAGES` 从同一注册表派生，保留现有只读模板映射兼容接口。其余公共、认证、错误、管理、诊断、审阅、对话、导入核对和独立打印模板在 `PAGES_BY_TEMPLATE` 统一声明。
- Flask的 `before_render_template` 依据实际选中的模板注入资源及页面元数据，避免请求里的view与真正渲染的页面不一致。非活动模板不受此钩子影响；遗漏活动页面映射会明确报错，覆盖测试也会发现漏配。
- `frontend/base.html` 只按资源列表输出标签，不再根据endpoint/blueprint/view分支选CSS/JS。认证、权限、业务查询与接口仍在既有路由/服务中。
- 公共资源和功能脚本顺序由Python维护，编辑器core→sort→editor顺序不变。打印页独立使用tokens/components/document/resume四个CSS及resume-print脚本，保留文档排版。

## 自动版本

应用启动时读取全部已登记静态资源，按文件内容计算SHA-256前16位作为每个文件自己的查询版本；未改变的文件可复用缓存。覆盖主题、公共/功能CSS与JS、HTMX/Alpine和打印页。无需手写日期、构建号或修改模板中的版本字符串。内容哈希不依赖mtime；更换资源后需重启应用来载入该次部署的指纹表。没有新增依赖或运行时打包器。

## 上传、留白与可供性

岗位页访客PDF入口采用真实button触发隐藏的原文件input，保留字段ID、文件限制、CSRF、解析接口和代际/错误处理。中文按钮支持键盘，单独回显文件名、读取状态及更换入口；不显示浏览器Choose File/No file chosen。选错格式仍由原校验拒绝，服务端验证不变。

移动端岗位表单增加底部88px与安全区余量、提交说明区间距和控件滚动余量，保留同一个吸底提交条。

次级按钮采用共享surface-3表面；禁用按钮保持文字可读，使用弱化文字、禁止光标且不触发活动悬停反馈。沿用无边框、主题和输入焦点规则；自动对比度检查不能代替真实用户可用性研究。
