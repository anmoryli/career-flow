# 职序 V1 高定 UI 契约

本轮以用户提供的十条规则为最高设计要求，参考三个已读取的 Skill 入口及组件/移动输入手册：

- https://github.com/Ludi-Herry/b-end-design-system-skill/blob/main/SKILL.md
- https://github.com/Ludi-Herry/mobile-design-system-skill/blob/main/SKILL.md
- https://github.com/Ludi-Herry/desktop-agent-ui/blob/main/SKILL.md

沿用 Flask/Jinja/HTMX/Alpine/Tailwind 与当前 Landing 任务架构。未安装外部 Skill 包、引入依赖或复制仓库组件代码。仓库的微边框、后台模板与用户无边框、Landing 要求不一致时采用用户要求。规则的具体实现独立编写。

| 规则 | 实现与边界 |
| --- | --- |
| 微明度、无边框 | 浅色 f5f5f3/fcfcfb；暗色 0b0b0a/151515/1a1a19/20201e。应用容器去描边，以表面、间距、字体和语义色分层。状态、错误及选中仍有文字。A4纸张沿用可打印白底，不改用户文档内容。 |
| 双环输入焦点 | 统一 inset 1px + outer 3px box-shadow，无输入 outline。键盘按钮仍有可见焦点；强制颜色模式保留系统可辨识边界。 |
| 暗色 -40 | 所有应用字号权重改用共享变量，暗色逐级减40（400→360等）；继承与无字重简写也使用变量。固定字体是否有对应真实字重受设备字体支持影响，不伪称引入了可变字体。 |
| 流式晕开 | 单字90ms、blur 6px→0、相邻30ms，曲线 .215/.61/.355/1。只处理真实 partial 内容；校验完成立即同步全文，不用动画伪造进度或延迟采用。归并已完成字符节点，文本从不作为HTML执行。 |
| 图标基线 | 行内 icon vertical-align:-0.125em。 |
| 数字稳定 | 应用 tabular-nums；复制按钮预留宽度。 |
| 折叠 | 原生 details 保留键盘/分组语义；Grid 0fr→1fr，不用JS测高。关闭内容 inert，防止Tab进入折叠区；不支持 details-content 的浏览器回退原生展开。 |
| 防孤字 | 正文、列表、引用使用 text-wrap:pretty。 |
| 两种弹簧 | 质量1的数值积分生成关键帧：拖拽1200/80，确认380/18。板块重排使用无回弹轨迹，勾选/复制成功微弹；拖拽分栏支持Escape复位。 |
| 反馈自熄 | AI替换稿可复制，成功后显示对勾，2.5s后淡出恢复；失败不显示成功。复制测试使用可控剪贴板stub，不冒充系统剪贴板验收。 |

`craft.js` 与 `craft.css` 定义共享行为/状态，功能脚本仅接入流式结果和重排。`tokens.css` 和功能 CSS 将硬编码权重归一，不再各页维护暗色补偿。用户偏好 reduced-motion 时关闭字晕、位移、弹簧和折叠过渡，切换偏好也会取消运行中的弹簧。移动端增加安全区、IME提交守卫和聚焦可见性；含表单弹窗不因点遮罩静默关闭。

- 实际查看暗色登录与输入焦点截图；完整三端三主题截图生成不等于逐张人工审阅。

未调用收费模型、真实支付或执行生产部署；未验证真机软键盘、系统剪贴板、Safari/Firefox。当前全站和弹簧/流式测试均在隔离 Chromium 浏览器与测试供应商中运行。
