# 操作可发现性修复

先调研、后改动。本轮基于440ec42实际活动页面及用户“需要寻找操作”的反馈。

## 设计依据

- [NN/g — Recognition and Recall](https://www.nngroup.com/articles/recognition-and-recall/)：让可执行的选项可见，减少依赖用户记住菜单位置。
- [GOV.UK — Button](https://design-system.service.gov.uk/components/button/)：动作使用具体动词与对象；主操作明确，次操作不争抢；长页面应减少判断负担。
- [W3C — Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：目标大小与间距共同影响激活难度。项目继续采用主要触控控件44px的既有更高目标，不把WCAG的24px最低要求误称为44px。

这些原则指导以下具体修改，不引入外部组件代码、框架或默认后台导航。

## 发现与修复

| 发现 | 修改 |
| --- | --- |
| 简历和报告入口藏在“我的内容”下 | 顶部直接显示我的简历、岗位分析、分析报告；低频模板和记录保留更多菜单 |
| 头像缺少操作提示 | 显示“账号”文字，仍用原设置/会员/退出菜单 |
| 页面大标题占据首屏而操作靠下 | 简历库、导入、模板、岗位、报告与审阅采用直接任务标题，收紧任务页首；营销首页仍保留品牌叙事 |
| 编辑器保存次要，导出主要；手机隐藏分析/历史/导入文字 | 保存简历改主按钮，导出次级；手机工具分行显示文字，保留会员标识、主题与帮助，主要控件44px |
| 简历行必须进菜单才能开始岗位分析，最近工作被导入方式压到下方 | 已有简历时最近工作先于起点介绍；行内直接显示继续编辑和岗位分析，重命名/副本/删除保留明确“更多” |
| 岗位分析必须找页面底部 | 原提交区移至form直接子级并吸底，仍是同一个真实按钮/校验/接口，不复制任务触发器 |
| 长审阅页保存入口被段落遮远 | 紧凑吸顶条显示实时选择数量，明确“前往保存岗位版”，跳至原命名/核实/保存区；不跳过真实性确认 |
| 已有分析的重新分析入口太靠下 | 在服务状态及诊断状态允许时同步出现在页首，继续受原幂等、轮数和权限限制；完成报告不开放只读限制之外的操作 |

保留无边框表面、字重补偿、动效降级和自定义下拉；没有改变业务API、数据库、会员/账本或AI内容采用规则。

## 验证

- 前端构建、`analysis_review.js` 与新增浏览器用例语法检查、暂存差异检查通过。
- 前端资源清单与基础检查：`tests/test_frontend_manifest.py`、`tests/test_foundation.py` 共16项通过。
- 新增操作专项在1440×1000、820×1180、390×844三种尺寸检查：导航直接可见、编辑器保存/分析/历史/导入控件在视口内、最近简历继续编辑在视口内、行内分析入口无需展开菜单、分析真实按钮在视口内、审阅保存锚点在视口内、实时选中数量、真实性确认与另存后的原简历保护。
- 首轮专项暴露了提交footer实际嵌套在section中的问题，修正为form直接子级后6项通过。最终暂存代码隔离复测：desktop 2/2、tablet 3/3、mobile 4/4通过；后两者还覆盖下述失败流程。
- 扩展浏览器回归69项：66通过、3失败。覆盖用户/管理页面及公共认证页的浅色、深色、跟随系统、溢出检查，编辑器触控、键盘、自定义下拉、减少动态效果、导入/导出、逐段审阅等。
- 三项失败分别为tablet补充另存、mobile活动页面资源检查、mobile编辑与设计保存。保留的网络trace分别记录了analysis.js、resume-import文档请求、commerce/orders请求的`net::ERR_ADDRESS_IN_USE`。初次隔离复测脚本未正确传入Windows尺寸参数，实际仍为desktop，不计为平板/手机验收；该次desktop页面资源检查也出现相同连接错误。修正参数并换用独立端口后，在对应tablet/mobile尺寸下三条流程均通过，没有修改断言或应用逻辑来掩盖失败。
- 人工查看了桌面岗位/审阅和手机编辑器/岗位/审阅截图；本地8000进程已重启，GET岗位页返回200并含新导航及`20261030-actions`资源版本。

浏览器业务流程使用真实测试MySQL和现有测试供应商，不调用付费模型或真实支付。未做真实用户可用性研究，也未验收Firefox/Safari；自动检查不能证明用户一定能立即发现所有操作。
