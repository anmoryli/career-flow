# 简历编辑器：隐藏、折叠与条目层级

## 原因与范围

隐藏板块原先仅在 `resume-core.js` 的文档预览中被过滤。`resume-editor.js` 仍对全部 section_order 生成顶部定位与编辑表单，还附一行“已隐藏”说明，因此用户选择隐藏后仍在上下两处看见该板块。

本次仅调整活动前端控制器、样式与资源版本，不改变简历API、数据库、CSRF、版本规则、会员权限或AI采用规则；不引入依赖。原有内容留在同一份document中。

## 行为

- 隐藏：顶部定位、编辑表单、预览共同遵循 hidden_sections；编辑区末尾提供“管理已隐藏板块”，进入原有设计/板块设置恢复。保存、刷新后仍隐藏，恢复时保留原文。
- 折叠：每个编辑板块标题是可键盘操作的直接按钮，单击收起/展开，无需先打开菜单。aria-expanded 与 aria-controls 同步；Grid 1fr/0fr过渡，不测量高度；关闭内容 inert，减少动效时不做过渡。
- 折叠只属于当前编辑器会话状态，不修改简历或创建版本。添加、重排等重建表单保留其他板块折叠状态；点击定位有意展开目标。
- 板块设置菜单保持原生details语义，不参与内容折叠包装，关闭时明确不显示菜单内容；支持一次点击开关、点击外部关闭及Escape返回菜单按钮。照片/更多信息仍保留原有details折叠。
- 分层：标题区、编辑面、条目使用已有主题表面与间距区分，无新增描边；条目有清晰编号，操作区有独立按钮。
- 添加：板块标题旁提供“添加工作经历”等快捷按钮，列表末尾保留完整宽按钮；共用同一个本地添加操作和数量限制。点击后定位并聚焦新条目首字段，保留此前内容。没有自动生成经历。

- 仅暂存代码隔离检出后，三端专项9项再次通过，覆盖隐藏保存刷新/恢复保留原文、单击与键盘展开收起、照片/更多信息单击关闭、菜单关闭与Escape、增加经历聚焦与实际测试库保存、其他板块折叠状态保留、浅/深/系统主题表面区分与页面溢出。

- 人工查看手机浅色与桌面深色截图，确认板块标题/经历编号/添加入口的层级。自动生成三尺寸三主题截图不代表全部逐张人工验收。
