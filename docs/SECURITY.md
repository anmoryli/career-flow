# 安全模型与当前边界

## 已实现

- 严格 MySQL/PyMySQL/utf8mb4 校验，独立随机配置秘密，生产强制 Secure Cookie、MySQL TLS、SMTP TLS，模拟支付生产禁用。
- 密码 scrypt 哈希；随机长会话 Token 仅在 HttpOnly/SameSite=Lax Cookie 中，数据库只保存摘要；单会话与全部会话撤销。
- 注册码六位随机数字、HMAC 存储、10 分钟失效、最多五次错误、单次使用、邮箱发送间隔和 IP/账户频率限制。
- Redis Lua 原子限流并设置 TTL，Redis 故障时认证服务返回 503，不绕过保护。
- 注册、登录、消息、事实、删除、主题写操作均检查 CSRF；SQLAlchemy 参数化查询与服务端资源所属权。
- Jinja2 默认转义、同源资源 CSP；Alpine CSP 构建与 HTMX 禁止 eval/内联指示器样式。
- 不记录密码、验证码、Cookie、数据库连接串或完整对话；错误仅记录分类和请求编号。
- 只有明确确认的记忆进入上下文；对话删除级联清除消息与记忆，不使用缓存恢复删除数据。

## 边界与尚未完成项

- 邮箱验证码密码重置已实现，验证码仅存摘要、最多五次错误、十分钟失效，成功后撤销全部会话；账户注销和管理员撤销指定用户会话也已实现。细分管理员角色与完整业务审计尚未实现，当前仅有管理员布尔权限和部分管理操作审计。
- 当前有受控 PDF 文件上传与待启用的模型诊断；外部 JD 抓取和任意工具执行入口未开放。
- 本地 SMTP/Mailpit 为开发捕获用途，不投递互联网邮件；开发收件箱仅绑定回环地址。
- Windows Worker 是 SimpleWorker + TimerDeathPenalty 开发模式，没有 Linux Worker 的子进程隔离；生产和资源密集任务必须使用 Linux 原生 Worker。
- 会话设置 Secure=False 仅供本机 HTTP；生产配置校验阻止这一设置。
- WSL 初始安装使用 root 修改系统开发服务配置，生产环境应由运维独立配置并使用最小权限账户。
- 原生 Mailpit 从固定官方 HTTPS release 下载，记录 SHA256、验证 ZIP CRC；该 release 无上游校验文件，不宣称验证过发布者签名。
- Nginx HTTPS、生产备份策略、依赖更新策略和性能压力测试尚未上线验收。
# 2026-10-24 用户业务扩展

新增所有写API继续使用CSRF/认证，并对每个资源验证所属人。业务写限流240次/分钟，PDF导入10次/分钟；JSON/上传总请求限5MB。诊断仅服务器配置模型，不接受用户指定API地址或任意工具。

照片通过签名和Pillow解码、尺寸校验；仅允许PNG/JPEG/WebP。PDF不使用上传文件名构造路径，不抓取外部链接，任务限时120秒，限4MB/20页/100000文字；二进制完成后删除。Windows开发Worker隔离弱于Linux生产Worker，不据此宣称恶意PDF资源耗尽风险完全消除。

扫描页仅在 PDF 无可提取文字时执行 Tesseract OCR：页面渲染限制为最多约 500 万像素，单页 OCR 最长 20 秒，总识别预算 90 秒，Worker 上限 120 秒；原始文件与渲染图不写入持久文件。OCR 输出仍需用户核对，不自动认定为真实简历事实。

模型输入排除照片，显式标记不可信数据；输出经Pydantic及逐字证据校验，建议仅接受字段白名单并需用户确认。供应商异常仅记录类型，禁止记录密钥、原始异常和完整简历；无有效费用数据时不能成功结算。模型默认关闭，测试提供者仅TESTING可用。

管理端路由每次请求在服务端检查 `users.is_admin`；初始管理员只可从本地 CLI 创建，普通注册不能自升权限。邮箱授权码与模型 API Key 在管理员配置表中使用独立 `ADMIN_CONFIG_KEY` 派生的 Fernet 密钥加密，响应、历史列表和审计只包含“已配置”状态。密钥丢失或变更后旧配置不能解密；生产环境应在密钥管理系统中保存并备份该值，轮换需专门迁移。管理员配置的发布和回滚保留历史版本，新的诊断报价绑定模型版本；已确认任务使用原版本执行。真实付费联调仍需明确费用上限。
