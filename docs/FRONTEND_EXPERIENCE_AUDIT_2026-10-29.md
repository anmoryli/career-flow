# V1 前端体验审计与实施清单

本轮基线：dc2a2e0。先检查 AGENTS、当前路由映射、活动模板、共享样式/脚本、依赖、现有浏览器测试和上轮截图。原有未提交修改另存忽略目录 output/experience-baseline，保留在原处。本轮不修改后端业务或新增依赖。

活动入口为 frontend/base.html；workspace_template 映射 11 个工作空间视图，公共、后台、诊断及导入路由直接指向 frontend。旧 interface.css 等不再活动；先前设计文档中的旧入口需更新。

## 逐页审计

| 页面 | 当前问题 | 本轮实施方向 |
| --- | --- | --- |
| 公共首页 | 标题抽象；多个同权重长段介绍；预览焦点弱 | 明确简历价值、放大真实预览、合并 AI/岗位流程、渐进展开 |
| 登录/注册/找回 | 表单说明偏轻、主次入口分散 | 表单优先、更清晰辅助信息和下一步 |
| 总览 | 装饰持续旋转；下一步不随已有工作变化 | 依据实际简历/岗位/结果呈现准备路径，最近工作优先 |
| 简历库 | 创建入口同权、文档名称/操作偏小 | 一个主要创建入口，更易读的文档和空状态 |
| 模板选择 | 预览与选择说明分散 | 明确选择→编辑步骤，扩大触控与选中反馈 |
| PDF 导入/核对 | 上传与核对的连续性弱 | 明确提取、人工核对、保存三步和失败返回 |
| 简历编辑器 | 控件偏密、保存/预览联动弱 | 保持工作区比例，加强字段/章节层级与真实状态反馈 |
| 岗位分析 | 填写字段与开始后行为的联系不够明显 | 步骤引导、就地字段反馈、真实处理中状态 |
| 诊断/追问 | 证据、追问、任务记录权重接近 | 结果→依据→行动，减少重复主操作 |
| 段落审阅 | 内容比较/选用/保存的状态转换弱 | 明确比较后选择、已选择状态和保存前核对 |
| 报告 | 查找与阅读下一步弱 | 突出结果入口与审阅修改路径 |
| 历史/个人对话 | 空状态行动不集中 | 记录优先、筛选反馈、明确继续入口 |
| 会员/订单 | 价格以外说明偏轻 | 周期/权益/支付状态可读，保留真实开通限制 |
| 设置 | 侧栏比重偏高，安全操作密集 | 内容和保存优先，危险操作独立保留 |
| 后台总览 | 数据和下一步间关联弱 | 工作入口清晰，保留真实统计 |
| 后台用户/订单/审计 | 密集文本、表格横向使用感弱 | 共享字号与对比、可聚焦滚动、明确筛选与状态 |
| 后台配置 | 长表单操作反馈需突出 | 分组层级与保存/激活反馈，保留安全字段 |
| 共用组件 | 10–12px 辅助文字和按钮、弱对比 | 共享排版/动效 Token、44px 触控、焦点、错误/空/加载状态 |
